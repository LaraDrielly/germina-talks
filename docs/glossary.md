# Glossário — Germina Talks

Termos de domínio usados em specs, código e documentação. Mantenha consistência ao escrever novos artefatos.

| Termo | Definição |
|-------|-----------|
| **Germina Talks** | Plataforma de comunidade escolar do Instituto J&F |
| **Instituto J&F** | Centro de Educação para os Negócios, mantenedor do projeto |
| **Sala** | Unidade organizacional equivalente a turma/classe (ex: "3º ano ADS 2026") |
| **Frente de ensino** | Escola de Negócios, Escola de Tecnologia ou Escola da Fábrica |
| **Escopo global** | Conteúdo visível para toda a comunidade escolar autenticada |
| **Escopo de sala** | Conteúdo visível apenas para membros da sala |
| **Publicação (post)** | Mensagem curta no feed, estilo tweet |
| **Mural (bulletin)** | Recado informativo, pode ser fixado e ter data de expiração |
| **Álbum** | Coleção de fotos agrupadas por evento ou tema |
| **Foto** | Imagem individual dentro de um álbum |
| **Fixar (pin)** | Destacar recado no topo do mural |
| **Membro** | Usuário vinculado a uma sala com papel específico |
| **Aluno** | Papel padrão — pode publicar e visualizar conforme escopo |
| **Professor** | Pode fixar recados, moderar conteúdo da sala |
| **Coordenação** | Pode publicar comunicados globais e moderar em escopo amplo |
| **Change** | Mudança OpenSpec com proposal, design, tasks e spec delta |
| **Spec** | Especificação de comportamento (fonte da verdade em `openspec/specs/`) |
| **Delta spec** | Alteração proposta em uma change, antes de ir para a spec principal |
